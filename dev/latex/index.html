Using it in LaTeX

Preamble

\usepackage[T1]{fontenc}
\usepackage{lmodern}   % or any scalable font
\usepackage{tikz}
\usepackage{graphicx}  % only if figures contain heatmaps, images or rasterised plots

With the default fontsize = :native, text nodes request exact sizes such as \fontsize{10.5}{12.6}, so use a scalable font: lmodern, fix-cm, or any OpenType font under LuaLaTeX/XeLaTeX. Plain OT1 Computer Modern substitutes the nearest size and warns. With LuaLaTeX/XeLaTeX and a Unicode font, pass unicode = false to keep characters such as −, ° and Greek letters as they are.

Matching the document

LaTeX typesets the text, but Makie's layout decided where it goes and how much room it gets. For the best match, build the figure at its final size and font size, and let Makie measure text with Computer Modern:

with_theme(latex_theme(fontsize = 10)) do      # 10pt text, Computer Modern metrics
    fig = Figure(size = size_pt(345, 200))     # 345pt = \textwidth of a 10pt article
    ...
    savetikz("fig.tex", fig)
end
  • size_pt converts TeX points to Makie units (1 unit = 0.75pt by default, as in CairoMakie's PDFs).
  • latex_theme sets Makie's font size so text comes out at the requested size, and switches Makie to Computer Modern so its layout measures text the way LaTeX will set it.
  • The whole picture can be rescaled in LaTeX by editing x=0.75pt, y=0.75pt in the tikzpicture options. Line widths and text keep their absolute size.

To find your document's text width, put \showthe\textwidth in it and look in the log.

Images and file layout

Heatmaps, images and rasterised plots are written as PNGs next to the .tex file (plot.tex → plot-1.png, …). \includegraphics resolves paths relative to the main document, so if you \input{figures/plot.tex} either pass image_prefix = "figures/" to savetikz or add \graphicspath{{figures/}} to the preamble.

Rasterising heavy plots

Set Makie's own rasterize attribute on a plot to embed it as an image while everything else stays vector and LaTeX. This needs CairoMakie loaded:

using CairoMakie, TikzMakie
scatter!(ax, huge_points; rasterize = true)   # rasterize_scale px per unit (default 4)
surface!(ax3, xs, ys, zs; rasterize = 6)      # or an explicit px per unit

Tables and other raw LaTeX

Makie cannot draw a tabular (its LaTeX renderer only does math), but TikzMakie can pass one through. RawLaTeX is text that goes into the picture verbatim, while Makie's layout and other backends see a plain-text preview. It works anywhere Makie takes text: text!, Label, titles.

latextable builds one from any table with PrettyTables.jl. The LaTeX comes from PrettyTables' LaTeX backend (booktabs rules by default) and the preview from its text backend, so Makie reserves roughly the space the table will take:

using CairoMakie, TikzMakie, PrettyTables

data = [1 0.12 "a"; 2 3.4 "b"; 3 56.7 "c"]
labels = [LatexCell(L"n"), LatexCell(L"x"), "label"]

fig = Figure(size = size_pt(345, 150))
ax = Axis(fig[1, 1]; xlabel = L"t", ylabel = L"\sin t")
lines!(ax, 0 .. 10, sin)
# an inset, on a white background so the data doesn't show through
text!(ax, 0.98, 0.97; text = latextable(data; column_labels = labels, background = "white"),
      space = :relative, align = (:right, :top))
# a table in its own layout cell
Label(fig[1, 2], latextable(data; column_labels = labels); tellheight = false)

savetikz("table.tex", fig; standalone = true, preamble = "\\usepackage{booktabs}")

The table is set at the text's font size. In your own document, add \usepackage{booktabs} to the preamble (or pass booktabs = false). Keywords meant for one PrettyTables backend only go in latex = (; ...) or text = (; ...).

Options

All keywords of tikz/savetikz are listed in TikzOptions. The most useful:

optiondefault
pt_per_unit0.75TeX points per Makie unit.
fontsize:native:native sets each node's size from Makie; :inherit uses the surrounding document's size.
numbers_as_mathtrueNumeric strings (tick labels) are set in math mode: $-1.5$, $10^{-3}$.
displaystylefalsePrefix math with \displaystyle, so \frac/\int are full size, as Makie draws them.
unicodetrueReplace −, °, ×, Greek letters, … with LaTeX commands (for pdfLaTeX).
textfilteridentityFunction applied to each node's LaTeX string.
backgroundfalseDraw the figure background (false = transparent).
standalonefalseWrap in a compilable standalone document.
preamble""Extra preamble lines for standalone, e.g. "\\usepackage{booktabs}".
image_prefix""Prefix for \includegraphics paths.
simplify0.05Line simplification tolerance in Makie units. 0 disables.
rasterize_scale4Pixels per unit for plots with rasterize = true.
