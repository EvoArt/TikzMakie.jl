API

TikzMakie.tikz — Function
tikz(fig; kwargs...) -> TikzFigure

Convert a Makie Figure, FigureAxisPlot or Scene to TikZ. See TikzOptions for the keyword arguments. The result's code is a tikzpicture environment (or a standalone document with standalone=true); raster images it references are in images and are written by savetikz.

TikzMakie.savetikz — Function
savetikz(path, fig; kwargs...)
savetikz(path, t::TikzFigure)

Write the TikZ code for fig to path (usually .tex) and any images next to it as <name>-<n>.png. Include the result in a document with \input{path}. Returns path.

TikzMakie.TikzFigure — Type
TikzFigure

Result of tikz: the TikZ code (String(t) or t.code) plus any raster images (t.images, filename => pixels) that the code references. Save both with savetikz.

TikzMakie.TikzOptions — Type

Options controlling TikZ output. Every field can be passed as a keyword to tikz and savetikz.

  • pt_per_unit = 0.75: size of one Makie unit in TeX points. 0.75 matches CairoMakie's PDF output, so a 600×450 figure becomes 450pt×337.5pt.
  • digits = 2: decimals written for coordinates (in Makie units).
  • fontsize = :native: :native sets each text node's size from Makie (\fontsize), so the text fills the space Makie's layout reserved; :inherit leaves the document's font size alone.
  • numbers_as_math = true: typeset purely numeric strings (tick labels) in math mode, $-1.5$.
  • unicode = true: replace common Unicode symbols (−, °, Greek, …) with LaTeX commands for pdfLaTeX. Set false for LuaLaTeX/XeLaTeX with a Unicode font.
  • textfilter = identity: function applied to the final LaTeX string of every text node, for custom substitutions.
  • background = false: draw the figure's background colour. false leaves the picture transparent (axis backgrounds are still drawn).
  • standalone = false: wrap the picture in a compilable standalone document.
  • preamble = "": extra preamble lines for the standalone document, e.g. "\\usepackage{booktabs}" for a latextable.
  • image_prefix = "": prepended to image file names in \includegraphics, e.g. "figures/" when the .tex is \input from a parent directory.
  • image_basename = "tikzmakie": stem of image file names (set automatically by savetikz).
  • max_upsample = 2048: non-interpolated images (heatmaps) are upsampled with nearest-neighbour to at most this many pixels per side, so PDF viewers cannot blur them.
  • color_prefix = "mkc": prefix for \definecolor names.
  • clip_padding = 0.25: geometry further than this fraction of the figure size outside the figure is cut in Julia (TikZ cannot handle huge coordinates).
  • simplify = 0.05: lines are simplified (Ramer–Douglas–Peucker) with this tolerance in Makie units (0.05 units ≈ 0.04pt, far below visibility). Dense lines shrink a lot. 0 disables.
  • rasterize_scale = 4: pixels per Makie unit for plots with rasterize = true (≈ 380 dpi at the default pt_per_unit). An integer rasterize = n ≥ 2 on the plot uses n instead (Makie stores true as 1). Needs CairoMakie loaded.
  • strut = true: give every text node at least the height and depth of a parenthesis, as Makie aligns text by font ascender/descender rather than by the glyphs' ink. Keeps e.g. an x axis label at the same distance from the tick labels as in Makie.
  • displaystyle = false: prefix math in LaTeXStrings with \displaystyle, so \frac, \sum and \int are full size, as Makie draws them (and as Makie's layout reserved space for them).

TikzMakie.latex_theme — Function
latex_theme(; fontsize = 10, pt_per_unit = 0.75, latexfonts = true)

A Makie theme for figures destined for LaTeX: text of fontsize points once written with savetikz at pt_per_unit, and (with latexfonts = true) Computer Modern fonts so that Makie's layout measures text close to how LaTeX will typeset it.

with_theme(latex_theme(fontsize = 10)) do
    fig = Figure(size = size_pt(345, 220))
    ...
end
source
TikzMakie.size_pt — Function
size_pt(width, height; pt_per_unit = 0.75)

Figure size in Makie units for a picture of width×height TeX points. For an article's \textwidth (345pt): Figure(size = size_pt(345, 220)).

TikzMakie.RawLaTeX — Type
RawLaTeX(latex; preview = latex)

Text that TikzMakie writes into the picture verbatim, as LaTeX source, while Makie (its layout, CairoMakie, GLMakie, …) sees only preview. Use it for LaTeX that Makie cannot draw itself, such as a tabular:

tbl = raw"\begin{tabular}{rr} \toprule a & b \\ \midrule 1 & 2 \\ \bottomrule \end{tabular}"
text!(ax, 0.95, 0.95; text = RawLaTeX(tbl; preview = "a  b\n1  2"),
      space = :relative, align = (:right, :top))
Label(fig[1, 2], RawLaTeX(tbl; preview = "a  b\n1  2"))

RawLaTeX is an AbstractString that behaves like preview, so it works anywhere Makie takes text. Makie reserves space for the preview, so make the preview roughly the size of the typeset result. The node keeps its font size, colour, alignment and rotation; the LaTeX is not escaped and its line breaks are not treated as line breaks.

latextable builds one from a table with PrettyTables.jl.

source
TikzMakie.latextable — Function
latextable(data; booktabs = true, background = nothing, latex = (;), text = (;), kwargs...) -> RawLaTeX

A table for a Makie figure, typeset by LaTeX in TikzMakie's output. Needs PrettyTables.jl loaded (using PrettyTables). data is anything pretty_table accepts (a matrix, a vector, a Tables.jl table).

The LaTeX comes from pretty_table(String, data; backend = :latex, ...), and the RawLaTeX preview, which Makie draws and sizes, from the :text backend. Keywords:

  • kwargs...: passed to both backends (column_labels, formatters, alignment, …). LatexCells are shown in the preview without $, {} and backslashes.
  • latex, text: named tuples of keywords for one backend only.
  • booktabs = true: \toprule/\midrule/\bottomrule (needs \usepackage{booktabs}) unless latex sets table_format.
  • background: an xcolor name such as "white", to set the table on an opaque \colorbox (useful for insets over data).
using CairoMakie, TikzMakie, PrettyTables
tbl = latextable([1 0.12; 2 3.4]; column_labels = [LatexCell(L"n"), LatexCell(L"x")])
text!(ax, 0.98, 0.97; text = tbl, space = :relative, align = (:right, :top))
Label(fig[1, 2], tbl; tellheight = false)
savetikz("fig.tex", fig; standalone = true, preamble = "\\usepackage{booktabs}")

The preview uses the text's font, so its columns only line up in a monospace font (font = "DejaVu Sans Mono" if installed); the size Makie reserves is approximate either way.
